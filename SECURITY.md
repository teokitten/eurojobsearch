# Security Policy

## Reporting a vulnerability

If you find a security issue in this project, please report it privately using GitHub's [private vulnerability reporting](https://github.com/teokitten/eurojobsearch/security/advisories/new) feature (Security tab → "Report a vulnerability"), rather than opening a public issue or pull request.

Please include:
- A description of the vulnerability and its potential impact
- Steps to reproduce it
- Any suggested fix, if you have one (optional)

## What to expect

This is an independently maintained open-source project. I'll acknowledge reports as soon as I can, generally within a few days, and let you know once a fix is out. There's no bug bounty, but genuine reports are credited in the fix commit and, where applicable, in a published security advisory.

## Scope

This applies to the code in this repository (`templates/index.html`, `app.py`, `docs/index.html`, and related files). Issues in third-party dependencies should be reported to those projects directly.
